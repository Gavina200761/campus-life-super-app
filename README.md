# campus-life-super-app
The Campus Life Super App.This is a hub for everything you need to be successful in school. It includes tools that can help with your day-to-day life, and a wellness page to assist in healthier living as a student.
I used HTML, JavaScript, CSS, bootstrap, google calendar, random motivational quote API.
I structured my code so that it will function properly and connected it to the other pages for flawless redirection. I used github pages to launch my site and it is working as intended.
There are lots of ways to interact with each page, such as pressing the buttons at the bottom of my index.html file, which will give you the remaining time before the indicated event will occur. Many other resources are included as well through other buttons on other pages.
Future improvements include a better design/appearance for the website.
